# PracticalFunction

PracticalFunction is a mod for **Monster Black Market** —— adding some Practical Function and allowing customizing some game settings.

### Features

| Type        | Function                                    | Description                                                                |
| ----------- | ------------------------------------------- | -------------------------------------------------------------------------- |
| Function    | Drag During Pause                           | Allow Dragging Units during Pause.                                         |
| Function    | Game Speed Extensions                       | More Game Speed multipliers.                                               |
| Function    | Disable Slave Escape                        | Prevent Slave Escape from Brothel.                                         |
| Function    | One-Click Sell                              | Sell Character on Delete Key Press.                                        |
| Function    | Dismantling Limit                           | Flora's Overwork Dismantle Limit (-1 = Immune to overwork).                |
| Customizing | Start Gold                                  | Initial Funds at Game Start.                                               |
| Customizing | Private Estate Cost                         | Personal Estate Price.                                                     |
| Customizing | Cost Of Disposing Corpse                    | Slave Corpse Disposal Cost.                                                |
| Customizing | Cost Of Disposing Infertile Monster         | Infertile Monster Disposal Cost.                                           |
| Customizing | Percent That Changes To Drain               | The percentage of Health at which a Slave becomes Drained.                 |
| Customizing | Pixy Move Duration Multiplier               | Pixy move duration multiplier.                                             |
| Customizing | Game day length                             | Game day length in seconds.                                                |
| Customizing | Rest Time                                   | The time in seconds that a Slave will rest before starting a new activity. |
| Customizing | Body Decays Time                            | Body decays time in seconds.                                               |
| Customizing | Time To Die/Infertile From Venereal Disease | Time to Death/Fertility after STD Infection in seconds.                    |
| Customizing | Loan Period                                 | Loan Period (Days) .                                                       |
| Customizing | Max Essence                                 | Maximum Essence Storage.                                                   |
| Customizing | Price Of Tentacle Egg                       | Tentacle Egg Selling Price.                                                |
| Customizing | Essence Of Tentacle Egg                     | Tentacle Egg Essence Conversion Value.                                     |
| Customizing | Essence For Tentacle Room                   | Essence Cost to Build Tentacle Room.                                       |
| Customizing | Egg For Tentacle Room                       | Tentacle Eggs Required to Build Tentacle Room.                             |

### Requirements

| Dependency           | Version |
| -------------------- | ------- |
| MBM.ModLoader        | latest  |
| Monster Black Market | latest  |

### Compatibility

- ✅ **TitsMod** — allow using the Default ConfigData of Tits Mod.
